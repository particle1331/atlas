Lessons and experiments reconstructed from [Jam With AI’s Production Agentic RAG project](https://github.com/jamwithai/production-agentic-rag-course), following its seven weekly releases from infrastructure and ingestion to hybrid retrieval, grounded generation, observability, and bounded agent workflows. The explanations connect the code to engineering decisions: how to preserve evidence, recover from partial failure, evaluate retrieval and answers, and justify added complexity. These are independently written lessons based on the available source and notebooks, rather than a reproduction of the original recorded course.

Each lesson combines worked examples, small executable experiments, source-level commentary, and a full-system Docker lab with expected observations and failure-injection checks. The small experiments isolate mechanisms; the Docker system is the integration proving ground. Docker labs are documented for execution on a capable machine and are not presented as completed measurements. The aim is to develop engineering judgment through explicit contracts, reproducible experiments, and evidence that the system behaves as intended.

The companion code changes with each weekly release. This repository keeps a separate, unmodified source snapshot for each post under `projects/production-agentic-rag/week1` through `week7`, with exact upstream commits recorded in `projects/production-agentic-rag/releases.json`. Use the matching week's code when following a lesson; the latest release is not a substitute for earlier implementations.
